# Coffee AI Bot

Telegram-бот для учета трат на кофе, написанный на Python (`aiogram`).

Сейчас бот поддерживает базовый сценарий:
- добавление траты;
- просмотр общей суммы;
- просмотр списка всех записей пользователя.

## Возможности

- `/start` — приветствие и подсказка по командам.
- `/add <сумма> [описание]` — добавить трату, например:
  - `/add 250 капучино`
  - `/add 199.90 латте`
  - `/add 180,5 фильтр`
- `/result` — показать итоговую сумму трат.
- `/list` — показать список всех добавленных трат.

Особенности:
- суммы обрабатываются через `Decimal` (корректнее для денег, чем `float`);
- каждый пользователь Telegram видит только свои записи;
- данные пока хранятся в памяти процесса (после перезапуска бота очищаются).

## Технологии

- Python 3.9+
- [aiogram](https://docs.aiogram.dev/)
- [python-dotenv](https://pypi.org/project/python-dotenv/)

## Быстрый старт

1. Клонируй репозиторий и перейди в папку проекта.
2. Создай и активируй виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установи зависимости:

```bash
pip install aiogram python-dotenv
```

4. Создай файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token
DB_PATH=coffee.db
```

5. Запусти бота:

```bash
.venv/bin/python bot.py
```

После старта в терминале появится лог:
`Бот успешно запущен ☕ Записываем траты на кофе...`

## Структура проекта

- `bot.py` — основной файл бота, хендлеры команд и запуск polling.
- `db.py` — заготовка SQLite: только `init_db()` создаёт таблицу `expenses` (бот пока её не вызывает).

## Важно про текущее состояние

Сейчас `bot.py` использует in-memory словарь `user_expenses`. Подключение SQLite к хендлерам — следующий поэтапный шаг.
