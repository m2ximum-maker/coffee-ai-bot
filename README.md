# Coffee AI Bot

Telegram-бот для учета трат на кофе, написанный на Python и `aiogram`.

Бот помогает записывать кофейные покупки, смотреть общую сумму и получать список сохраненных трат. Данные хранятся локально в SQLite.

## Возможности

- `/start` - приветствие и список доступных команд.
- `/add <сумма> [напиток] [кофейня]` - добавить трату.
- `/result` - показать общую сумму трат пользователя.
- `/list` - показать список всех трат пользователя.

Примеры:

```text
/add 250
/add 250 капучино
/add 250 капучино Surf Coffee
```

Сейчас сумма должна быть целым числом в рублях. Значения вроде `199.90` или `180,5` пока не поддерживаются.

## Как это работает

- Каждый пользователь Telegram видит только свои записи.
- При старте бот вызывает `init_db()` и создает таблицу `expenses`, если ее еще нет.
- Записи сохраняются в SQLite-базу, путь к которой задается через `DB_PATH`.
- Для запуска используется long polling через `aiogram`.

Таблица `expenses` содержит:

- `id` - идентификатор записи;
- `user_id` - Telegram ID пользователя;
- `amount` - сумма в рублях;
- `drink` - напиток;
- `coffee_shop` - кофейня, если указана;
- `created_at` - дата и время создания записи.

## Технологии

- Python 3.9+
- `aiogram`
- `python-dotenv`
- SQLite

## Быстрый старт

1. Создай и активируй виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установи зависимости:

```bash
pip install aiogram python-dotenv
```

3. Создай файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token
DB_PATH=coffee.db
```

4. Запусти бота:

```bash
.venv/bin/python bot.py
```

После запуска в терминале появится:

```text
Бот успешно запущен ☕ Записываем траты на кофе...
База данных инициализирована
```

## Структура проекта

- `bot.py` - основной файл бота: настройка `Dispatcher`, команды и запуск polling.
- `db.py` - функции для работы с SQLite: создание таблицы, добавление записей, список трат и сумма.
- `coffee.db` - локальная SQLite-база, не должна попадать в git.
- `.env` - локальные переменные окружения, не должен попадать в git.

## Git

В репозиторий стоит добавлять исходный код и документацию. Локальные файлы окружения, база данных, виртуальное окружение и системные файлы игнорируются через `.gitignore`.
